### 🔑 Contributor Onboarding
1. **Locate Your Target:** Navigate to a Sector above, then select your assigned Sub-Sector repository.
2. **Access Requirements:** Ensure you have been added to your local sub-sector GitHub Team to gain push/write permissions.
3. **Download Content:** Clone only your specific sub-sector repository locally using `git clone`.
